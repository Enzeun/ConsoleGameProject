### C# Console RPG
---
## 프로젝트 개요
C#의 객체지향 프로그래밍과 자료구조를 학습하기 위해 제작한 콘솔 기반 RPG 프로젝트입니다.
단순히 게임을 완성하는 것보다 Unity 프로젝트로 확장할 수 있는 C# 코드 구조를 직접 설계하고 구현하는 것을 목표로 진행했습니다.

## 실행 방법
폴더 최 상단에 있는 
"ConsoleGameProject.exe"
바로가기 파일로 실행

## 주요 학습 및 구현
- C# 객체지향 프로그래밍class
  - interface
  - abstract
  - virtual / override
  - 캡슐화 및 책임 분리

- 이벤트 기반 구조event
  - delegate
  - Action

- 자료구조
  - Dictionary
  - PriorityQueue

- 알고리즘
  - Dijkstra

- 게임 시스템 설계
  - 플레이어 / 몬스터 / 아이템 등의 객체 설계
  - 전투 및 게임 진행 로직 구현

## 프로젝트를 통해 배운 점
게임 기능을 구현하는 것보다 각 객체의 책임을 어떻게 나누고, 이후 기능이 추가되었을 때 구조를 어떻게 유지할 것인지를 고민하는 경험에 집중했습니다.
특히 Unity 프로젝트에 들어가기 전에 C#의 객체지향 설계와 자료구조를 직접 사용해보면서, 이후 Unity에서 게임 시스템을 설계할 때 필요한 기본기를 쌓는 것을 목표로 했습니다.
학습 목적의 프로젝트이므로 기능의 규모보다는 C#과 객체지향 설계 원리를 직접 적용해본 경험에 의미를 두었습니다.
